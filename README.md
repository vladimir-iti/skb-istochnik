# Сайт СКБ «Источник»

Статический сайт специального конструкторского бюро «Источник» (Ростов-на-Дону):
инжиниринг, продукция, металлообработка и промышленная автоматизация.

Без фреймворков и зависимостей — Node-сборщик собирает чистый HTML/CSS/JS,
который кладётся на любой обычный хостинг.

## Как запустить

```bash
cd site && node build.js --serve
```

Сборка без сервера:

```bash
cd site && node build.js
```

Результат — в `site/dist/`. Именно эту папку заливают на хостинг.

## Структура

```
tools/
  prepare-images.py подготовка картинок из source-materials → site/src/images
site/
  build.js          сборщик: собирает страницы, копирует статику в dist/
  partials/
    data.js         ВСЁ содержимое сайта: контакты, разделы, услуги, изделия
    header.js       шапка (две строки: контакты + меню)
    footer.js       подвал
    mobileNav.js    мобильное меню
    leadBlock.js    блок заявки (#lead) — в конце каждой страницы
    icons.js        инлайновые SVG-иконки
  templates/
    section.js      ШАБЛОН страницы раздела — используется 4 раза
    item.js         ШАБЛОН страницы услуги/изделия — используется 23 раза
    blocks.js       блоки главной, собираемые из data.js
  pages/            страницы со своей вёрсткой: главная, о компании, контакты, политика
  src/
    css/            tokens → base → components → header-footer → pages
    js/main.js      анимации появления, шапка, мобильное меню, форма
    images/
  dist/             результат сборки (в git не хранится)
source-materials/   исходники заказчика: тексты, рендеры, фото, PDF
```

## Как править контент

Почти всё правится в одном файле — `site/partials/data.js`:

- контакты (телефоны, почта, адрес) — объект `CONTACTS`;
- разделы и их услуги/изделия — массив `SECTIONS`;
- преимущества, этапы работы, отрасли — `ADVANTAGES`, `PROCESS`, `INDUSTRIES`.

Добавили позицию в `SECTIONS` → после `node build.js` у неё появляется своя
страница, карточка в разделе, пункт в мегаменю и ссылка в подвале. Отдельный
HTML писать не нужно.

## Изображения

Все картинки готовит `tools/prepare-images.py`: берёт исходники заказчика,
кадрирует под нужные пропорции (16:9 для первого экрана, 4:3 для карточек),
ужимает и раскладывает в `site/src/images/`.

```bash
python3 tools/prepare-images.py
```

Скрипт идемпотентный — после новых материалов от заказчика достаточно положить
файлы в `source-materials/`, дописать их в списки в начале скрипта и запустить
заново. Что откуда берётся:

| Источник | Что получаем | Куда идёт |
|---|---|---|
| `Рендеры/*/*.JPG` | 6 моделей защиты стеллажей × 2 ракурса | карточки и галерея продукции |
| `Рендеры/*/*.pdf` | габаритные чертежи ЕСКД | блок «Габаритные чертежи», инжиниринг |
| `источник-1.pdf` | 7 рендеров установки ТГЗ-1000 | страница пожарной установки |
| `Ещё/Untitled.pdf` | 4 рендера установки KorMax | страница рекуперации |
| `Ещё/Габаритные КорМакс500.PDF` | габаритный чертёж KorMax | характеристики KorMax |
| `Блок №3/*.heic` | лазерная резка, заготовки, готовые детали | металлообработка, первый экран |
| `Производство/*.jpg` | сварочный участок | сварка, сварочные столы, лента на главной |
| `generated/*.jpg` | **сгенерированные кадры** | автоматизация, сканирование, окраска, гибка, изделия |

Рендеры лежат внутри PDF с альфа-масками — скрипт достаёт их и накладывает
на белый фон. HEIC и PDF конвертируются системными `sips` и `qlmanage`,
поэтому скрипт работает на macOS.

Отобранные кадры зафиксированы по номерам объектов в PDF (`FIRE_PICKS`,
`KORMAX_PICKS`) и по именам файлов (`LASER`, `STOCK`, `PANELS`) — если
понадобится другой ракурс, правится один список.

### Сгенерированные кадры

32 изображения сгенерированы под проект — там, где у заказчика нет своих
фотографий. Лежат в `site/src/images/gen/`, задание на генерацию —
в `tools/image-brief.md`. Подробности: **[GENERATED-IMAGES.md](GENERATED-IMAGES.md)**.

Вопросов с лицензиями нет. Но это не съёмка реального производства бюро,
поэтому по мере появления своих фотографий их стоит заменять.

## Стили

Единая дизайн-система на CSS-переменных, `site/src/css/tokens.css`:

- фирменный тёмно-синий `#04295A` взят из логотипа, акцент — `#1F6FD0`;
- строгая сетка, почти прямые углы (радиус 4px), заглавные подписи;
- анимация одна на весь сайт — класс `.reveal` (появление при скролле),
  плюс мягкая сетка-«калька» на первом экране. Всё отключается при
  `prefers-reduced-motion`.

## Что осталось сделать

1. **Заснять реальное производство.** Автоматизация, 3D-сканирование, гибка,
   порошковая окраска, колёсоотбойники, столбики, опоры и шкафы показаны
   сгенерированными кадрами — см. [GENERATED-IMAGES.md](GENERATED-IMAGES.md).
   Юридически они чистые, но своё фото цеха убедительнее.
2. **Отправка формы.** Сейчас форма проверяется на клиенте и показывает
   подтверждение. Реальную отправку (почта/CRM) подключаем вместе с хостингом —
   точка входа в `site/src/js/main.js`, блок «Форма заявки».
3. **Раздел «Статьи».** В ТЗ он есть (блок №5), но материалов пока нет —
   раздел не собирается.
4. **Домен.** В `partials/data.js` указан `SITE.origin = https://skb-istochnik.ru` —
   поменять на фактический перед публикацией (влияет на canonical и sitemap).
