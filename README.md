# Сайт СКБ «Источник»

Статический сайт специального конструкторского бюро «Источник» (Ростов-на-Дону):
инжиниринг, продукция, металлообработка и промышленная автоматизация.

Без фреймворков и зависимостей — Node-сборщик собирает чистый HTML/CSS/JS,
который кладётся на любой обычный хостинг.

## Как запустить

```bash
cd site && node build.js --serve
```

Сборка без сервера:

```bash
cd site && node build.js
```

Результат — в `site/dist/`. Именно эту папку заливают на хостинг.

## Структура

```
site/
  build.js          сборщик: собирает страницы, копирует статику в dist/
  partials/
    data.js         ВСЁ содержимое сайта: контакты, разделы, услуги, изделия
    header.js       шапка (две строки: контакты + меню)
    footer.js       подвал
    mobileNav.js    мобильное меню
    leadBlock.js    блок заявки (#lead) — в конце каждой страницы
    icons.js        инлайновые SVG-иконки
  templates/
    section.js      ШАБЛОН страницы раздела — используется 4 раза
    item.js         ШАБЛОН страницы услуги/изделия — используется 23 раза
    blocks.js       блоки главной, собираемые из data.js
  pages/            страницы со своей вёрсткой: главная, о компании, контакты, политика
  src/
    css/            tokens → base → components → header-footer → pages
    js/main.js      анимации появления, шапка, мобильное меню, форма
    images/
  dist/             результат сборки (в git не хранится)
source-materials/   исходники заказчика: тексты, рендеры, фото, PDF
```

## Как править контент

Почти всё правится в одном файле — `site/partials/data.js`:

- контакты (телефоны, почта, адрес) — объект `CONTACTS`;
- разделы и их услуги/изделия — массив `SECTIONS`;
- преимущества, этапы работы, отрасли — `ADVANTAGES`, `PROCESS`, `INDUSTRIES`.

Добавили позицию в `SECTIONS` → после `node build.js` у неё появляется своя
страница, карточка в разделе, пункт в мегаменю и ссылка в подвале. Отдельный
HTML писать не нужно.

## Стили

Единая дизайн-система на CSS-переменных, `site/src/css/tokens.css`:

- фирменный тёмно-синий `#04295A` взят из логотипа, акцент — `#1F6FD0`;
- строгая сетка, почти прямые углы (радиус 4px), заглавные подписи;
- анимация одна на весь сайт — класс `.reveal` (появление при скролле),
  плюс мягкая сетка-«калька» на первом экране. Всё отключается при
  `prefers-reduced-motion`.

## Что осталось сделать

1. **Фотографии.** У части позиций пока нейтральная заглушка
   (`/images/common/placeholder.jpg`): колёсоотбойники, парковочные столбики,
   опоры освещения, металлические шкафы, лазерная резка, труборез, гибка,
   порошковая окраска, изготовление под ключ. Нужны реальные снимки —
   после этого достаточно проставить путь в `data.js`.
2. **Отправка формы.** Сейчас форма проверяется на клиенте и показывает
   подтверждение. Реальную отправку (почта/CRM) подключаем вместе с хостингом —
   точка входа в `site/src/js/main.js`, блок «Форма заявки».
3. **Раздел «Статьи».** В ТЗ он есть (блок №5), но материалов пока нет —
   раздел не собирается.
4. **Домен.** В `partials/data.js` указан `SITE.origin = https://skb-istochnik.ru` —
   поменять на фактический перед публикацией (влияет на canonical и sitemap).
